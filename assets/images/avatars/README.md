# Avatar Images

This directory contains default avatar images for different user types:

- `child-default.png` - Default avatar for children (ageGroup 1, role: member)
- `adult-default.png` - Default avatar for adults (coaches, admins, ageGroup 2 members)

## Usage

These images are used as fallbacks when users haven't uploaded custom profile pictures.

## Replacement

You can replace these placeholder images with actual designed avatars. Recommended dimensions:
- Size: 100x100px minimum (will be scaled as needed)
- Format: PNG with transparent background
- Style: Consistent with app design theme

## Current Status

Currently using placeholder images. Replace with actual designed avatars when available.
